Git dan GitHub adalah tools yang digunakan dalam pengembangan perangkat lunak.

Git merupakan sistem version control yang berfungsi untuk mencatat, mengelola, dan melacak perubahan kode program di komputer.

GitHub merupakan platform online untuk menyimpan repository Git, membagikan kode, dan berkolaborasi dengan programmer lain.

Beberapa perintah dasar Git:
- git init: Membuat repository baru.
- git add .: Menambahkan file yang akan disimpan.
- git commit: Menyimpan catatan perubahan.
- git push: Mengirim kode ke GitHub.
- git pull: Mengambil perubahan terbaru dari GitHub.
- git clone: Menyalin repository ke komputer.
Kesimpulan: Git digunakan untuk mengelola perubahan kode, sedangkan GitHub digunakan untuk menyimpan dan membagikan kode secara online.
