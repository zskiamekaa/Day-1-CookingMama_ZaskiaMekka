## Deskripsi Repository
Repository ini merupakan tempat penyimpanan dokumentasi kegiatan workshop dan hasil praktik pembuatan website Study Planner.

Study Planner adalah website sederhana yang dirancang untuk membantu mahasiswa mengatur tugas kuliah, deadline, prioritas, dan memantau progres belajar.

## Tujuan
1. Mempelajari dasar pembuatan website.
2. Memahami penggunaan HTML, CSS, dan JavaScript.
3. Membuat aplikasi sederhana untuk mengelola tugas.
4. Mempelajari penggunaan Git dan GitHub sebagai media penyimpanan project.

## Fitur Website
- Menambahkan tugas kuliah.
- Menentukan mata kuliah.
- Mengatur deadline tugas.
- Menentukan prioritas tugas.
- Menandai tugas yang sudah selesai.
- Menghapus tugas.
- Melihat progres penyelesaian tugas.
- Menyimpan data menggunakan Local Storage.

## Teknologi yang Digunakan
- HTML
- CSS
- JavaScript
- Git
- GitHub

## Dokumentasi Workshop
Repository ini juga digunakan untuk menyimpan materi, rangkuman, catatan pembelajaran, dan hasil praktik selama kegiatan workshop berlangsung.
